# Prince Hassan Group

Public marketing site for Prince Hassan Group. Recreated from the Squarespace original as a frontend-only Next.js app for Vercel.

## Pages

- `/` — About
- `/advisory` — Real Estate Advisory
- `/markets-properties` — Markets & Properties
- `/experiences` — Experiences
- `/contact-prince` — Contact Prince

## Local

```bash
npm install
npm run dev
```

## Deploy

Push this repo to GitHub and import it in [Vercel](https://vercel.com/new). No environment variables are required.
